# Model as a function

`rrmsdessetup()`RRMS DES model inputs written as a function to be called
from Shiny APP `rrmsdesmodel()`RRMS DES model run written as a function
to be called from Shiny APP

## Usage

``` r
rrmsdessetup(
  drc = drc,
  drq = drq,
  time_horizon = time_horizon,
  p_eid = p_eid,
  jcvtest_cost = jcvtest_cost
)
```

## Details

For exclusive use of SHINY APP.
