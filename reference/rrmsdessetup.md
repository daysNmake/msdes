# SetupModel as a function

`rrmsdessetup()`RRMS DES model inputs written as a function to be called
from Shiny APP

## Usage

``` r
rrmsdessetup(
  drc = drc,
  drq = drq,
  time_horizon = time_horizon,
  p_eid = p_eid,
  jcvtest_cost = jcvtest_cost
)
```

## Details

For quick deployment, also used in ShinyApp.
