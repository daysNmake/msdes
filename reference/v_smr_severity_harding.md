# A matrix of excess all cause mortality for MS patients by severity

A matrix of excess all cause mortality for MS patients by severity

## Usage

``` r
v_smr_severity_harding
```

## Format

A matrix with `3` rows and `10` columns. Each column contains the data
by EDSS severity state:

- smr:

  average standard mortality ratio by severity state

- sd:

  standard deviationby severity state

- logsd:

  log standard deviation by severity state

## Source

edss\<4 (Jick et al), edss\>=4 (Harding et al)
