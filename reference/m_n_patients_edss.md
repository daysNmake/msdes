# Patient counts by EDSS score

A matrix of patient counts stratified by EDSS score.

## Usage

``` r
m_n_patients_edss
```

## Format

A matrix with `2` rows and `10` columns. Each column contains the number
of patients at that EDSS score:

- harrms:

  distribution of patients

- rrms:

  distribution of patients

## Source

AFFIRM baseline
