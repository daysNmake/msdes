# Annual treatment scheduled load factors years 1-5

A matrix of annual treatment scheduled load factors years 1-5

## Usage

``` r
df_c_tx_load
```

## Format

A matrix with `5` rows and `8` columns. Each column contains the
percentage of patients treated/re-treated by by DMT, with the 5 rows
repenting the load factors during the first years.

## Source

UoB_TAG analysis (refer to report)
