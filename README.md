# MS-MTA repository
This repository stores the data and scripts necessary to run the economic model and generate all necessary input parameters, including those generated by network meta-analysis.
We follow the format of the DARTH framework. 
This model code is **not complete**
An important todo is to modeularise the DESCEM scripts into functions

## To extract data
DO NOT RUN; the data has already been extracted in the data-raw folder and saved in the data folder with links to it specified in the model.

Go to data-raw/Run all raw data scripts.R to run scripts below:

data-raw/MS registry.R to extract registry data

data-raw/serious_adverse_events.R to extract SAEs cost utilities and weights

data-raw/all_cause_mortality.R to extract all cause_mortality life tables

data-raw/costs.R to extract heath state and relapse costs, but treatment acquisition (df_c_drugs.csv) administration (df_c_drugs_admin.csv) and monitoring (df_c_monitoring.csv) costs are saved manually (to be automated) in the data folder

data-raw/utilities.R to extract heath-state, relapse and carer utilities

data-raw/relapse_severity.R to extract proportions and annual rates of relapse by severity

## To run the model
Go to analysis/descem_rrms_5_1.R

#### Relapsing
 + Baseline Drawn form MS Registry data for RRMS and SPMS patients then modified by ARR HR from NMA
 
#### Severity increase
 + Baseline Drawn form MS Registry data for RRMS and SPMS patients then modified by CDP-3/CDP-6 HR from NMA

#### Severity decrease
 + Baseline Drawn form MS Registry data for RRMS  patients only, no relative treatment effect applied

#### Progression to RRMS
 + Baseline Drawn form MS Registry data for RRMS  patients only, no relative treatment effect applied
  
#### Treatment switching
 +	Driven by treatment discontinuation due to SAEs, patients start on 2nd line and are allowed to switch up to 4th line treatment

#### Serious Adverse Events
 +	Weighted average Serious Adverse Events specific to Natalizumab to be modified by HR from safety NMA
 
#### Mortality
 + UK general population Age and sex dependent mortality modified by MS specific standardised mortality ratio
 
#### Costs
 + Ongoing health state costs (events: all ) associated with severity states (RRMS or SPMS)
 + instant annual treatment costs (events: annual_treatment ) currently set for 3 years
 + instant relapse costs (events: relapse )
 + instant SAE costs (events: serious_adverse_event)
 
#### Utilities
 + Ongoing health state utilities (events: all) associated with severity states (RRMS or SPMS)
 + instant relapse utilities (events: relapse )
 + instant SAE utilities (events: serious_adverse_event)
 + TO BE ADDED Ongoing carer disutilities (events: all)
