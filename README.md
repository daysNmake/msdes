# MS-DES repository (Update to reflect change over to WARDEN)
This folder stores the data and scripts necessary to run the economic model and generate all necessary input parameters, including those generated by network meta-analysis.

We follow the format of the DARTH framework. The scripts to run are in the "analysis" folder, processed data in "data" which includes the network meta-analysis results, and the functions in the "R" folder.

This model code is ** complete, but being switched over from descem to WARDEN**

## Installing WARDEN (Update to reflect change over to WARDEN)
The model relies on the [WARDEN](#ref-201) package. Documentation and tutorials on the usage of WARDEN can be found at https://jsanchezalv.github.io/WARDEN/index.html

Install the WARDEN package from CRAN by `install.packages("WARDEN") #CRAN version` 


## To run the model(Update to reflect change over to WARDEN)

+ From within RStudio (Not R GUI) open the project "MS-MTA_model_public"
+ A. Go to "analysis/ID6369 MS MTA Public Prices_ACM2_CPA_ACU_post_hoc.R" to run the model
+ B. Go to "analysis/post_hoc_analysis_loop_over_patients_simulations _3nats.R" to run the post_hoc analysis and get the results
+ By default `n_patients` and `n_samples` are set to `100` but it is advised to try running this with a smaller number as a test (e.g., `5` each). Running with the full `1000` each may take up to 3 days. Convergence checks found that `100` each was sufficient for experimentation.
+ For threshold analysis apply additional to `th_dic` discount on line 180, by default set to 0. The model must be re-run and the `threshold_table` saved, once for every additional discount applied.
+ When happy with settings, run the entire script.
+ This uses `source()` to load functions from the R directory that are necessary to run the model.
+ Note that there are warnings() about NAs being generated by rexp() but these can be ignored.

## Other scripts (Update to reflect change over to WARDEN)

There are two further scripts in the "analysis" subfolder. These can be run after the main "analysis/ID6369 MS MTA Public Prices_ACM2_CPA.R" has been run.


+ The script "convergence_check_1_1.r" runs a convergence test. Note that this requires `1000` patients and `1000` samples to have been run in the simulation.

+ The script "voi_rrms_1_1.R" runs the value of information analysis



## Custom functions(Update to reflect change over to WARDEN)

There are four functions in the "R" folder

+ "RunSim_new.R" provides the `RunSim_new()` function which can be used instead of the `descem::RunSim()` function. The changes are to allow custom random seeds and to store the sampled input parameters which are needed for value of information analysis.

+ "draw_tte_new.R" provides the `draw_tte_new.R` function which can be used instead of `descem::draw_tte()`. The only change is to provide the piecewise exponential distribution "pwexp" as an argument

+ "summarise_ce_results" provides the `summarise_ce_results()` function which generates a table of mean and 95% CrI for total costs, QALY, and net benefits relative to the specified `reference`

+ "summarise_samples.R" provides the `summarise_samples()` function which calculates the mean and 95% CrI for random samples (e.g. output from a probabilistic sensitivity analysis).

+ "summarise_tha_results" provides the `summarise_tha_results()` function which generates a table of mean and 95% CrI for incremental net benefits  and probability  INB is positive relative to the specified `reference at WTP£25,000/QALY

## To run the model
Go to analysis/descem_rrms_5_1.R

#### Relapsing
 + Baseline Drawn form MS Registry data for RRMS and SPMS patients then modified by ARR HR from NMA
 
#### Severity increase
 + Baseline Drawn form MS Registry data for RRMS and SPMS patients then modified by CDP-3/CDP-6 HR from NMA

#### Severity decrease
 + Baseline Drawn form MS Registry data for RRMS  patients only, no relative treatment effect applied

#### Progression to RRMS
 + Baseline Drawn form MS Registry data for RRMS  patients only, no relative treatment effect applied
  
#### Treatment switching
 +	Driven by treatment discontinuation due to SAEs, patients start on 2nd line and are allowed to switch up to 4th line treatment

#### Serious Adverse Events
 +	Weighted average Serious Adverse Events specific to Natalizumab to be modified by HR from safety NMA
 
#### Mortality
 + UK general population Age and sex dependent mortality modified by MS specific standardised mortality ratio
 
#### Costs
 + Ongoing health state costs (events: all ) associated with severity states (RRMS or SPMS)
 + instant annual treatment costs (events: annual_treatment ) currently set for 3 years
 + instant relapse costs (events: relapse )
 + instant SAE costs (events: serious_adverse_event)
 
#### Utilities
 + Ongoing health state utilities (events: all) associated with severity states (RRMS or SPMS)
 + instant relapse utilities (events: relapse )
 + instant SAE utilities (events: serious_adverse_event)
 + carer disutilities (events: all)
